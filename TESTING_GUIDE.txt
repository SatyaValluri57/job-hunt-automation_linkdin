================================================================================
   JOB APPLY BOT — COMPLETE TESTING GUIDE (Windows Device)
================================================================================
IMPORTANT NOTES:
  - config.py is NEVER pushed to GitHub (it's in .gitignore)
  - Fill config.py with REAL credentials ONLY on your local/test device
  - config.example.py has dummy values — that's the file in GitHub
  - Keep dryRun = True for first test (no real applications submitted)
================================================================================


------------------------------------------------------------------------
PHASE 1 — INSTALL PREREQUISITES (do this once)
------------------------------------------------------------------------

STEP 1: Install Git
  1. Open browser, go to: https://git-scm.com/download/win
  2. Download and run the installer
  3. Keep ALL default options → click Next all the way → Install
  4. Open Command Prompt (Windows + R → type cmd → Enter)
  5. Verify:
       git --version
     Expected output: git version 2.x.x

STEP 2: Install Python
  1. Go to: https://www.python.org/downloads/
  2. Download Python 3.11 (click the big yellow button)
  3. Run installer
     *** CHECK "Add Python to PATH" checkbox at the BOTTOM before clicking Install ***
  4. Click "Install Now"
  5. Verify in Command Prompt:
       python --version
       pip --version
     Expected: Python 3.11.x and pip 23.x

STEP 3: Install Google Chrome
  1. Go to: https://www.google.com/chrome/
  2. Download and install Chrome
  3. Open Chrome once to confirm it works → close it
  (ChromeDriver will be auto-downloaded later by the bot)


------------------------------------------------------------------------
PHASE 2 — GET THE CODE
------------------------------------------------------------------------

STEP 4: Open Command Prompt
  - Press Windows + R
  - Type: cmd
  - Press Enter

STEP 5: Clone the repository
  cd Desktop
  git clone https://github.com/satyavalluri57/YOUR-REPO-NAME.git
  cd YOUR-REPO-NAME

  (Replace YOUR-REPO-NAME with actual repo name from GitHub)


------------------------------------------------------------------------
PHASE 3 — INSTALL BOT PACKAGES
------------------------------------------------------------------------

STEP 6: Install required Python packages
  pip install -r requirements.txt

  Wait for it to finish. It installs:
    - selenium         (controls browser)
    - webdriver_manager (auto-downloads ChromeDriver)
    - selenium-stealth  (reduces bot detection)
    - pyyaml            (reads YAML config files)


------------------------------------------------------------------------
PHASE 4 — CONFIGURE (fill your details here — stays local only)
------------------------------------------------------------------------

STEP 7: Create your config file from template
  copy config.example.py config.py
  notepad config.py

  Notepad will open. Change ONLY these lines with your real values:

    email = "your_real_linkedin_email@gmail.com"
    password = "your_real_linkedin_password"
    keywords = ["Python Developer", "Backend Engineer"]
    location = ["Bangalore", "Hyderabad"]
    experienceLevels = ["Mid-Senior level"]
    datePosted = ["Past Week"]
    dryRun = True              ← KEEP THIS TRUE for first test
    maxApplicationsPerRun = 1  ← only 1 job for first test

  Save: Ctrl + S → close Notepad

  *** DO NOT run: git add config.py — it must stay local ***


------------------------------------------------------------------------
PHASE 5 — RUN THE BOT (DRY RUN / SAFE TEST)
------------------------------------------------------------------------

STEP 8: Run the bot
  python linkedin.py

  What you will see:
    - Chrome opens automatically
    - Bot navigates to LinkedIn login page
    - Logs in with your credentials
    - Searches jobs based on your filters
    - Opens Easy Apply form on a job
    - Fills in the form fields
    - DOES NOT SUBMIT (because dryRun = True)
    - Logs output in terminal
    - Chrome closes when done

STEP 9: Check the output log
  dir data\
  type "data\Applied Jobs DATA - *.txt"

  You will see which job the bot would have applied to.
  Verify the fields were filled correctly.


------------------------------------------------------------------------
PHASE 6 — ENABLE REAL APPLY (only after dry run is confirmed working)
------------------------------------------------------------------------

STEP 10: Switch to real apply
  notepad config.py

  Change these two lines:
    dryRun = False
    maxApplicationsPerRun = 5   ← start small, increase later

  Save → Run again:
    python linkedin.py

  Bot will now actually apply to jobs.


------------------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------------------

ERROR: python not found
  → Python not in PATH. Reinstall Python and check "Add to PATH"

ERROR: pip not found
  → Run: python -m pip install -r requirements.txt

ERROR: ChromeDriver version mismatch
  → Update Chrome to latest version. webdriver_manager handles the rest.

ERROR: LinkedIn login failed / CAPTCHA
  → Log into LinkedIn manually in Chrome once first
  → Then run the bot again (it reuses your session)

ERROR: No jobs found
  → Broaden your keywords or location in config.py
  → Change datePosted to "Past Month"
